# CalmWave Audio Benchmark API

FastAPI service that compares a clean reference recording with a processed recording and returns audio-quality metrics. It was built to support experiments around the CalmWave speech-enhancement project.

## What it does

- Accepts a reference and a processed audio file through multipart upload.
- Decodes files with SoundFile.
- Converts multichannel audio to mono before resampling.
- Resamples both signals to 16 kHz and aligns them to the shorter duration.
- Calculates PESQ, STOI and SDR when each metric accepts the supplied signals.
- Returns a JSON response; a metric may be null if its calculation fails.

## API

### GET /test

Returns a small health/test response.

### POST /benchmark

Multipart fields:

- clean_file: reference/clean audio
- denoised_file: processed audio to evaluate

Example:

    curl -X POST "http://localhost:8000/benchmark" ^
      -F "clean_file=@clean.wav" ^
      -F "denoised_file=@denoised.wav"

Example response shape:

    {
      "pesq": 2.445,
      "stoi": 0.860,
      "sdr": 14.980,
      "status": "success"
    }

Values above illustrate the response format only; they are not generated by this example request. Use results from your own audio files in reports.

## Run locally

Python 3.10+ is recommended.

    python -m venv .venv
    .\.venv\Scripts\Activate.ps1
    pip install -r requirements.txt
    uvicorn benchmark:app --host 127.0.0.1 --port 8000

Then open http://127.0.0.1:8000/docs for the interactive API documentation.

## Run with Docker

    docker build -t calmwave-api .
    docker run --rm -p 8000:8000 calmwave-api

After the container starts, open http://127.0.0.1:8000/docs.

## Implementation notes

- Upload reads are bounded to 10 MB per file.
- Very short recordings are rejected because the comparison may not be meaningful.
- The signals are converted to mono before resampling so multichannel audio is resampled along the time axis correctly.
- Signals are trimmed to the shorter recording; if timing alignment matters for an experiment, align the samples before submitting them.
- A successful HTTP response does not guarantee every metric is available. Inspect each metric field for null.

## Limitations and responsible use

This is an experimental evaluation API, not a clinical or diagnostic tool. Metrics do not fully describe human perception, and comparisons depend on correct alignment, sample rate, recording conditions and the chosen reference. Avoid uploading private voice recordings to public deployments; the API is intended for local or controlled research use.
